# Muthanna Tareq — Personal Portfolio

A responsive bilingual (English/Arabic) personal portfolio for Muthanna Tareq.

## Features
- English and Arabic language switch with RTL layout support
- Responsive navigation for mobile and desktop
- About, skills, projects, education, and contact sections
- Static HTML, CSS, and JavaScript — no build step required

## Deploy on Vercel
This repository is connected to the Vercel project **muthanna-tareq**.

- Production branch: `main`
- Production URL: https://muthanna-tareq.vercel.app
- Push or merge a commit to `main` to trigger a Vercel production deployment.
- Pull requests can be used to preview changes before merging.

If setting up a new Vercel project, import this repository, select **Other** (or the detected static configuration), keep the root directory as `./`, and deploy.
